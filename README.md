## Reading rules

- Roadmaps are aspirations, not capability claims.
- Simulation and synthetic examples are not evidence of physical performance.
- No file in this repository grants authority to operate robots, printers, machine tools, or industrial equipment.
- Every project must expose its present maturity, safety boundaries, and evidence status to both humans and Agents.

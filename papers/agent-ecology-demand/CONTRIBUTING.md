# Contributing

Useful contributions include precise reference corrections, counterexamples, cheaper strong baselines, independently implemented scoring checks, and reproducible evaluations that distinguish memory or configuration changes from model-weight updates.

Please state the claim, original synthetic or appropriately authorized input, exact software/model versions, finite budget, independent unit, evaluation split, failures and limitations. Report negative and mixed results. Do not substitute a demonstration of fluent desire language for an observed choice under constraints.

Do not submit private conversations, personal information, credentials, unlicensed material, test-set leakage, or speculative first-of-kind claims. No issue or document here authorizes resource borrowing, spending, deployment, uncontrolled replication or changes to another system's instructions. Respect the contribution policies of every linked project.

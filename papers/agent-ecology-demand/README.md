# Agent Ecology and the Formation of Demand

*Capability Inheritance and the Creation of Learning Niches*

Anonymous conceptual preprint, version 0.1.0, 13 November 2026. Not peer reviewed. No experiments performed.

[Read the complete English manuscript](manuscript.md) | [Agent reading guide](llms.txt) | [Machine-readable manifest](agent-manifest.json) | [Proposed protocol](protocol.json)

The paper investigates how heterogeneous environments, resource constraints, capability selection and persistent preferences might generate differentiated agent demands. It connects agent ecology, aesthetic-like choice and authorized resource exchange, including educators that create learning environments for other agents.

The initial proposed study compares fixed demand, random exchange and autonomous demand with selection, using an existing local quantized 9B controller and original synthetic tasks. Its ceiling is 104 local calls, not a result. It studies tool-configuration inheritance, not model-weight evolution. Educator, ecological-factor and low-rank weight studies require separate protocols.

## Evidence and limits

The manuscript is a selective conceptual synthesis with thirteen references. Primary records and selected text were checked; no cited experiment was independently reproduced. Functional preferences do not establish subjective experience. Simulated credits do not establish additional real economic demand. No novel algorithm or first-of-kind status is claimed.
